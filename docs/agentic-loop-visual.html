How an Agent Works — the Agentic Loop

An agent doesn't follow a fixed script. It reasons in a loop: understand → decide → act → observe — until the goal is done.

🤖
Agent
(LLM reasoning)
1

Understand

Read the user's message + context (the open record, the conversation, your instructions).

2

Decide

Reason about what to do next — answer directly, or pick the right action to call.

3

Act

Call an action: run a Flow, a Prompt Template, Apex, or a standard action (e.g. log a note, query records).

4

Observe

Read the result, decide if the goal is met. If not — loop again with what it just learned.
