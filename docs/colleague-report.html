What we built

1 · The installable package (Salesforce, unlocked)

One install link lands everything the attendee needs around the agent. No CLI, no Setup spelunking.

  • Employee Agent Workshop Lightning app with a Home launchpad
  • Workshop Launchpad LWC — a link to the guide + a one-click Run Setup that assigns the right permission sets to the attendee

Bugs found & fixed this round

  • App showed "No Items" — the Home tab had been rolled back by an earlier failed deploy + the perm set lacked tab visibility. Fixed.
  • Run Setup failed — it referenced a broken scaffold permission-set group (AFDX_User_Perms). Switched to assigning the standard out-of-the-box perm sets directly.
  • Namespaced perm-set lookup — force__… names weren't resolving. Fixed the controller's namespace handling.
  • Removed scaffold junk (weather demo classes, Resort_* perms, etc.) that was breaking the package build.
  • Accelerator name collisions — hardened to auto-pick a free name if the agent already exists.
