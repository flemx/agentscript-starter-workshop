# Agentforce Hackathon — research working notes

Scratch space for in-progress research: drafts, raw notes, API spelunking, source dumps,
half-formed angles (e.g. "how do we deploy an `AiAuthoringBundle` at runtime?", "which perm-set
assignment API works from an LWC?").

**This folder is NOT rendered by the portal.** Once a finding is source-cited and (ideally)
adversarially verified (see `command-center/HARNESS.md` §5), promote it into
`command-center/data/research.json` — that's the canonical, portal-rendered record (the
"Research Rounds" / Deep Research pages).

The reusable deep-research workflow lives at `command-center/research/research-workflow.mjs`
(angles are pre-scoped to this project — edit them as the unknowns shift).
